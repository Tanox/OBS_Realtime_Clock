# OBS 实时日期时间脚本

一个功能强大的 OBS Studio Lua 脚本，用于在直播场景中显示实时日期和时间，提供丰富的自定义选项。

## 功能特性

- **多语言界面**：支持中文 / 英文界面，可随时切换
- **文本源关联**：可关联到 OBS 场景中的任意文本源（GDI+ 文本 / FreeType 2 文本）
- **多种格式预设**：7 种预定义的日期 / 时间格式可选
- **自定义格式支持**：使用标准日期 / 时间格式符创建你自己的格式
- **时区支持**：本地时区或 UTC
- **灵活的更新间隔**：50ms 到 5000ms，可精细控制刷新频率
- **视觉自定义**：字体大小、颜色和字体（含 14 种常用字体预设 + 自定义字体）
- **显示 / 隐藏元素**：可切换秒、日期和时间的显示
- **自定义分隔符**：修改日期和时间中的分隔符
- **前缀 / 后缀**：在时钟前后添加自定义文本
- **大写选项**：全大写显示
- **对齐方式**：左对齐、居中或右对齐

## 安装

1. 下载 `realtime_clock.lua`
2. 打开 OBS Studio
3. 进入 **工具 → 脚本**
4. 点击 "+" 按钮
5. 选择 `realtime_clock.lua`
6. 在脚本设置中完成配置

> 要求 OBS Studio 28 及以上版本（支持 Lua 脚本的 `obslua` API）。

## 使用方法

### 基本设置

1. 在 OBS 场景中创建一个文本源（**GDI+ 文本** 或 **FreeType 2 文本**）
2. 打开脚本窗口（**工具 → 脚本**）
3. 选择 "实时日期时间" 脚本
4. 从 "文本源" 下拉菜单中选择你的文本源
5. 根据需要自定义其余设置

### 配置项说明

| 配置项 | 说明 | 取值范围 / 选项 |
|--------|------|----------------|
| 语言 | 脚本界面显示语言 | 中文 / English |
| 文本源 | 要更新的文本源名称 | OBS 场景中的文本源 |
| 格式类型 | 日期时间格式方案 | 自定义、默认、短日期、长日期、24 小时制、12 小时制、日期时间(短)、日期时间(长) |
| 自定义格式 | 自定义格式字符串（格式类型为"自定义"时生效） | Lua `os.date` 格式符 |
| 时区 | 时间计算基准 | 本地时区 / UTC |
| 更新间隔 | 刷新频率 | 50 – 5000 ms |
| 字体大小 | 文本字号 | 8 – 200 |
| 字体颜色 | 文本颜色 | 颜色选择器 |
| 字体样式 | 字体名称 | 14 种预设 / 自定义 |
| 自定义字体 | 选择"自定义"时输入的字体名 | 任意系统字体名 |
| 显示秒数 | 是否显示秒 | 开 / 关 |
| 显示日期 | 是否显示日期部分 | 开 / 关 |
| 显示时间 | 是否显示时间部分 | 开 / 关 |
| 日期分隔符 | 日期字段间的分隔字符 | 任意字符（默认 `-`） |
| 时间分隔符 | 时间字段间的分隔字符 | 任意字符（默认 `:`） |
| 前缀文本 | 时钟前添加的常量文本 | 任意文本 |
| 后缀文本 | 时钟后添加的常量文本 | 任意文本 |
| 大写显示 | 结果是否全大写 | 开 / 关 |
| 对齐方式 | 文本源内对齐 | 左对齐 / 居中 / 右对齐 |

### 格式说明符

在自定义格式中使用以下格式符（基于 Lua `os.date`）：

| 格式符 | 说明 | 示例 |
|--------|------|------|
| %Y | 4 位年份 | 2024 |
| %y | 2 位年份 | 24 |
| %m | 月份 (01-12) | 05 |
| %B | 完整月份名称 | 五月 |
| %b | 缩写月份名称 | 五 |
| %d | 日期 (01-31) | 23 |
| %A | 完整星期名称 | 星期四 |
| %a | 缩写星期名称 | 四 |
| %H | 小时 (00-23) | 14 |
| %I | 小时 (01-12) | 02 |
| %M | 分钟 (00-59) | 30 |
| %S | 秒 (00-59) | 45 |
| %p | AM/PM 标识 | 下午 |

> 提示：`大写显示` 开启后，星期、月份等中文名称不受影响；主要影响英文字母（如 `%p` 的 AM/PM）。

### 配置示例

- **默认效果**：`%Y-%m-%d %H:%M:%S` → `2026-08-13 14:30:45`
- **仅时间（无秒）**：格式类型选"24 小时制"，关闭"显示秒数" → `14:30`
- **带前缀**：前缀填 `北京时间：`，格式类型"自定义"，格式 `%H:%M:%S` → `北京时间：14:30:45`

## 常见问题

**Q：时钟不更新？**
A：请确认已正确选择"文本源"，且该文本源为 GDI+ 文本或 FreeType 2 文本类型；更新间隔不为 0。

**Q：修改格式后没生效？**
A：脚本在设置变更时会重新注册定时器。若仍无效，可在脚本窗口取消勾选再重新勾选脚本以重载。

**Q：自定义字体不显示？**
A：请确认系统中已安装该字体，且字体名称填写正确（区分大小写）。
