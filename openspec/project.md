# 项目规范

## 项目概述
OBS 实时日期时间脚本 - 一个功能强大的 OBS Studio Lua 脚本，用于在直播场景中显示实时日期和时间，提供丰富的自定义选项。

## 项目类型
- 脚本类项目

## 技术栈
- Lua
- OBS Studio

## 目录结构
```
obs_realtime_clock/
├── realtime_clock.lua    # 主脚本文件
├── README.md             # 中文文档（默认）
├── README_EN.md         # 英文文档
├── CHANGELOG.md         # 更新日志（中文）
├── CHANGELOG_EN.md     # 更新日志（英文）
└── openspec/
    └── project.md       # 项目规范文档
```

## 核心功能
1. 文本源关联：与 OBS 场景中的文本源绑定
2. 多种格式预设：提供 7 种预定义的日期/时间格式
3. 自定义格式支持：使用标准日期/时间格式符
4. 时区支持：本地时区或 UTC
5. 灵活的更新间隔：50ms 到 5000ms
6. 视觉自定义：字体大小、颜色和字体
7. 显示/隐藏元素：秒、日期、时间
8. 自定义分隔符：日期和时间分隔符
9. 前缀/后缀：在时钟前后添加自定义文本
10. 大写选项：全大写显示
11. 对齐方式：左对齐、居中、右对齐
